## Fix verification record

For each entry record: finding ID; reproducer and expected/actual; candidate scope; fixture/environment; failing case ID and pre-change commit; implementation/candidate commit; passing test/CI artifacts; independent QA executor and retest; adjacent regression cases; migration/rollback results if relevant; remaining defect IDs; verdict and timestamp. Redact secrets and real private content.

No closure from "could not reproduce" without named environmental explanation and evidence. No closure merely from a changed code path, passed type check, screenshot of a success toast, or a rewritten expected result. If intended behavior is unresolved, record the decision dependency and keep the feature blocked rather than encoding today's defect as the acceptance oracle.
